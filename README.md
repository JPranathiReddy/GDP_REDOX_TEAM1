Summary: 

We are developing an educational game, Redox-Protect the World, using the Godot engine. The game is designed to engage students by combining learning with a fun and interactive experience. It features a unique shooting mechanic that challenges players to answer questions by shooting the correct falling options. 

Gameplay Overview: 

Levels: The game consists of 4 levels, each progressively more challenging. To progress through the game, players must clear each level by answering questions correctly.  

Unlocking Levels: Players start at Level 1, and subsequent levels unlock only after the previous level is completed with a passing score. 

Questions & Lives: Each level presents 10 questions. Players are given 3 lives per level, meaning they can make up to 2 mistakes before the game ends for that level. 

Passing Requirement: Players need to answer at least 70% of the questions correctly (i.e., 7 out of 10) to clear a level and unlock the next one. 

Shooting Mechanic: During gameplay, various options fall from the top of the screen, and the player must shoot the correct one using the firing mechanism in the game.  

For each correct hit, the progress bar increases by 10%, indicating the player's advancement toward completing the level. 

Question Management: The game is supported by a web-based frontend built using Node.js and MySQL, allowing administrators to add, edit, and manage the set of questions for each level. This ensures flexibility in updating content and tailoring the game to different learning topics. 

User Management: The game also incorporates Firebase for user authentication, providing a secure login and registration system. This allows users to create accounts, track their progress across sessions, and ensures that each player's achievements are saved.
