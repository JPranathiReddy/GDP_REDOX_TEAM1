# Game Overview:

# Purpose of the Project : 
The purpose of this Gaming project is to create an engaging, educational game platform that combines fun gameplay with a structured learning experience. Players register to access four levels of progressively challenging content, where they must answer questions correctly to advance. A shooting mechanic is integrated, adding an interactive element as players select answers, with each correct choice moving them closer to completing the level. The game provides a web-based interface for administrators to manage questions, user progress, and overall performance, ensuring content is adaptable and informative. With Firebase for secure user management, the platform not only tracks achievements but also provides comprehensive data insights through downloadable reports, supporting ongoing player and content evaluation.

# Detailed Overview of Game:

**User Registration and Login:** The game begins with a registration and login page, where players must create an account to proceed. Users can register with any email to play; however, providing a valid email enables the option to reset a forgotten password through a change-password link sent to the registered email. There are no specific password requirements. Once registered, players can log in with the provided email and password.

**Instructions and Navigation:** Upon logging in, players will find an instructions icon to learn about the gameplay and controls. An exit button is available, allowing players to enter or exit as they wish.

**Game Levels:** The game features four levels, each designed to be progressively challenging. Players must complete each level successfully to unlock the next.

**Unlocking Levels:** Players start at Level 1. To advance, each level must be completed with a passing score, unlocking the subsequent level.

**Questions and Lives:** Each level includes 10 questions, with players given 3 lives per level. This allows for up to 2 incorrect answers before the level ends.

**Passing Requirement:** To clear a level and unlock the next, players need a minimum score of 70% (7 correct answers out of 10).

**Shooting Mechanic:** During gameplay, answer choices fall from the top of the screen, and players must use a shooting mechanism to select the correct answer according to the question prompt.

**Progress Tracking:** Each correct answer increases the player’s progress bar by 10%, indicating their advancement through the level.

**Audio Effects:** Aesthetic background music enhances the gameplay, along with sound effects for correct and incorrect answers, and firing actions, adding immersion to the experience.

**Win and Loss Screens:** Upon completing or failing a level, players are shown win or loss screens accompanied by exciting music and effects to boost engagement and encourage players to focus on the game.

**Question and User Management:** The game includes a user-friendly interface for the administrator to manage questions and answers within the database. Administrators must register using authorized credentials to access this management portal. Once logged in, the admin can add, modify, or delete questions and answers across the four game levels.
Additionally, administrators can view detailed user data, including the number of registered users and each player’s progress, completed levels, and scores. This data is presented in two formats: a bar chart overview and a detailed, scrollable list for individual user statistics. The admin also has the option to download user data as an Excel report for future reference.

# Setup Instructions and Steps to Run the Project:

1. Begin by downloading and installing the latest version of the Godot application.

2. Next, download the game’s zip file from the provided GitHub repository or use GitHub Desktop for easier tracking of future enhancements and bug fixes.

3. Once downloaded, extract the contents of the zip file. Navigate to the root folder, where the main game files are located, and copy the path, which should resemble C:\GDP-1\GDP_REDOX_TEAM1\Godot project\godot.

4. Open Godot Engine, click on "Import," and paste the copied path. Press Enter, select "Current Folder," and when the popup appears, choose "Import & Edit."

5. The game’s source code and scenes will now load into their respective areas within Godot.

6. To play the game, click the "Play" button in the top-right corner. You can also choose to run specific scenes individually using the available options.
